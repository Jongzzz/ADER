# 프로젝트 ADER: Triage 데이터 기반 실시간 응급 환자 위험도 예측 및 의사결정 지원 시스템

**Team:** Medecision 
**Role:** 팀장 / AI·웹 개발 총괄

---

## 1. 문제 정의 및 솔루션 방향 (Problem & Approach)
* **기존 응급실의 한계:** 기존 의료 현장에서는 단순한 수작업 분류나 챗봇 형태의 시스템만으로는 실시간 의사결정을 지원하기 어려웠으며, 사용 편리성 및 인터페이스에 한계가 존재했습니다[cite: 3].
* **ADER의 해결책:** 환자의 바이탈 사인 데이터를 바탕으로 실시간 객관적 중증도를 제공하는 AI 기반 응급환자 중증도 분류 시스템(CDSS)을 기획했습니다[cite: 3].
* **핵심 철학:** 통증(Pain) 가중치를 높게 설정하여 '환자 최우선' 원칙을 적용하고, 환자의 바이탈 변화 시 우선순위를 실시간으로 자동 재산출하는 시스템을 설계했습니다[cite: 3].

## 2. 데이터 통합 및 구조화 (Data Cleaning & Structuring)
* **대규모 임상 데이터 병합:** MIMIC-IV 데이터베이스의 vital, triage, diagnosis 등 5개 주요 테이블을 병합하여 통합적인 데이터 뼈대를 구축했습니다[cite: 3].
* **MICE 결측치 보정:** 결측치를 단순히 평균값으로 채우지 않고, 다른 변수들과의 상관관계를 다각도로 분석하여 빈칸을 예측 및 대치하는 MICE 기법을 적용했습니다[cite: 3].
* **노이즈 사전 차단 (Outlier Removal):** IQR(사분위수 범위) 방식을 활용하여 의학적으로 불가능한 수치를 자동 탐지하고, 학습 성능을 저해하는 노이즈 데이터를 사전에 완벽히 차단했습니다[cite: 3].

## 3. 모델링 및 하이브리드 로직 설계 (Modeling & Safety Mechanisms)
* **클래스 불균형 극복:** Random Forest 모델을 기반으로 `class_weight='balancing'` 파라미터를 적용하여, 데이터가 적게 분포한 고위험(Level 1-2) 환자 클래스에 가중치를 부여하고 예측력을 극대화했습니다[cite: 3].
* **파생 변수(Feature Engineering) 생성:** 맥박과 혈압 데이터를 결합하여 'Shock Index(쇼크 지수)' 파생 변수를 새롭게 생성함으로써, AI 모델의 급성 쇼크 감지 능력을 향상시켰습니다[cite: 3].
* **의학적 안전 장치 구현:** KTAS 기준을 융합하여 산소포화도(SpO2) 90% 미만(저산소증) 또는 수축기 혈압(SBP) 90 이하(저혈압 쇼크)인 환자는 즉시 최우선 등급(Level 1)으로 강제 지정하는 룰 기반(Rule-based) 안전망을 구축했습니다[cite: 3].

## 4. 실시간 웹 대시보드 및 시스템 구현 (Web Development & UI)
* **Streamlit 기반 실시간 UI:** 파이썬 Streamlit 프레임워크를 활용하여 환자 신규 등록, AI 분석 결과 도출, 대기열 현황 모니터링까지 단일 화면에서 처리 가능한 직관적 대시보드를 개발했습니다[cite: 3].
* **다차원 상태 시각화:** Plotly 레이더 차트를 도입하여 통증, 혈압 등 환자의 복합적인 상태를 의료진이 직관적으로 파악할 수 있도록 시각화했습니다[cite: 3].
* **데이터 추적성 확보:** 환자 고유 번호(ID) 생성 알고리즘을 도입하여 대기열 중복을 방지하고, 환자 데이터 및 로그를 CSV 파일 형식으로 안전하게 저장 및 관리하는 백엔드 시스템을 구현했습니다[cite: 3].

## 5. 기대 효과 및 비즈니스 임팩트 (Consequences)
* **임상적 측면:** 의료진의 피로도나 숙련도 편차에 따른 오분류를 데이터 기반 정량화로 방지하며, 육안으로 놓치기 쉬운 급성 악화 징후(Shock Index 등)를 조기에 탐지합니다[cite: 3].
* **운영 및 확장성:** 데이터 입력 즉시 중증도 등급을 제시하여 환자 분류 효율성을 높이고, 향후 EMR 연동 및 웨어러블 디바이스 기반의 실시간 활력징후 모니터링 시스템으로 확장할 수 있는 토대를 마련했습니다[cite: 3].
